# 银行账户管理系统代码注解

源代码：

```Java
        Scanner scanner =new Scanner(System.in);
        System.out.println("欢迎进入银行账户管理系统！");
        long balance = 0;
```

输出欢迎页面（只出现一次），开一个变量`balance`存储余额。由于这个变量无论何时、无论执行哪个操作都要用到，所以需要开在`while`循环外面。

```Java
        while(true)
        {  ...
        }
```

用`while(true)`进行一个无限循环，持续输出操作页面直到用户主动关闭。

```Java
            System.out.println("本系统提供的服务如下：\n1. 存款\n2. 取款\n3. 查询余额\n4. 退出\n");
            System.out.println("请输入服务序号，选择服务：\n");
            int choice = scanner.nextInt();
            switch(choice)
            {  ...
            }
```

输出操作菜单，用变量`choice`保存用户的选择。

利用`switch`语句，根据用户的选择进行对应操作。

```Java
                case 1 :
                    System.out.println("请输入存款金额：\n");
                    long deposit = scanner.nextLong();
                    if(deposit <= 0)
                    {
                        System.out.println("存款金额必须大于零！");
                    }
                    else
                    {
                        balance += deposit;
                        System.out.println("存款成功！当前余额为：" + balance + "\n");
                    }
                    break;
```

选择存款操作时，用`deposit`保存用户输入值，首先判断输入值是否合法，若输入的是正整数（题目要求不考虑小数情况）则存款成功，使余额加上输入值即可。

```Java
                case 2 :
                    System.out.println("请输入取款金额：\n");
                    long withdraw = scanner.nextLong();
                    if(withdraw <= 0)
                    {
                        System.out.println("取款金额必须大于零！");
                    }
                    else if (withdraw > balance)
                    {
                        System.out.println("余额不足！");
                    }
                    else
                    {
                        balance -= withdraw;
                        System.out.println("取款成功！当前余额为：" + balance + "\n");
                    }
                    break;
```

选择取款操作时，用`withdraw`保存用户输入值，与存款操作类似进行判断，注意还要判断是否能取出这么多钱。

```Java
                case 3:
                    System.out.println("当前余额为：" + balance + "\n");
                    break;
                case 4:
                    System.out.println("退出系统，感谢使用！");
                    break;
```

若要选择查看余额，输出`balance`的值即可；若要选择退出，先输出退出界面，此时没有真正的退出while循环，需要一会儿再写判断语句进行退出。

```Java
                default:
                    System.out.println("无效的序号，请重新输入！");
```

注意使用`default`语句考虑到输入的指令错误的情况。

```java
            if (choice == 4)
            {
                break;
            }
```

用一个另外的`if`语句，退出这个无限循环。
